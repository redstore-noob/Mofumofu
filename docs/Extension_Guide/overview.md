# Mofumofu Launcher 插件开发指南

> 插件API由我设计，但文档可能有部分AI参与，如果您觉得有不妥之处，请提交ISSUE，我将尽我能力进行完善。

插件系统一览：插件是 .NET 类库（实现 `IMofuPlugin`），打包成 `.nekoex` 安装，与启动器同进程运行。
能做什么：桌面小组件、页面注入、任务栏/托盘常驻、主题与样式、实例与资源下载、启动钩子……全部能力见 [第三章 API 对照表](3.API对照表.md)。

## 📋 文档规则

- **第三章是唯一的 API 速查表**，只放签名 / 权限 / 行为表格；场景类教程放"按目标找章节"指向的位置
- 第三章体量超过 300 行时按域拆分（3-UI / 3-下载 / 3-钩子），拆分前本目录会先更新
- 数据 record 与枚举统一放在契约库 `Data/` 目录，文档统一在第三章第 8 节索引
- 新增 API 的规矩：**先改第三章，再合并代码**——文档欠账会直接挡住作者的落地

## ⚠️ 写插件前必读三条

1. 插件与启动器**同进程**运行：只安装可信来源的插件，权限开关是知情同意机制不是沙箱
2. 清单里**声明权限**（`permissions:`），没声明的 API 调用会抛 `PluginPermissionException`
3. 别在控件里起停不下来的后台线程 / 定时器——热卸载需要配合（详见[第一章第 5 节](1.开发环境.md)）
