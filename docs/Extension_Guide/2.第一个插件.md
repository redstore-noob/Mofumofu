# 第二章：你的第一个插件

本章从零写一个真实可跑的插件：**圆形时钟**——它会弹一条提示，然后往桌面组件盒里加一个每秒走针的时钟。全程照抄能跑，改几行就是你自己的插件。


## 1. 创建项目

```bash
mkdir MyClock && cd MyClock
dotnet new classlib -n MyClock -f net10.0
```

按第一章第 3 节改好 csproj（引用 ExtensionAPI + 瘦身 Avalonia），然后加一个 `ClockPlugin.cs`：

## 2. 实现插件入口

插件入口 = 实现 `IMofuPlugin`，宿主靠它认出你：

```csharp
using Mofumofu.ExtensionAPI;
using Mofumofu.ExtensionAPI.UI;

public class ClockPlugin : IMofuPlugin
{
    public string Name => "圆形时钟";                    // 玩家在插件页看到的名字
    public Version Version => new(1, 0, 0);              // 插件版本
    public PluginTypeEnum ExtensionType => PluginTypeEnum.Tool;  // 分类标签
    public string Description => "往组件盒里加一个圆形时钟";

    public Boolean Init(IPluginContext context)
    {
        // Init 在加载时被宿主调用一次，context 是你使用宿主能力的唯一通道
        context.Popup.Toast("圆形时钟插件已加载喵！");
        context.Widget.WidgetAdd("clock", new ClockWidget());
        context.Log("初始化完成");
        return true;   // 返回 false = 拒绝加载（比如检测到环境不满足）
    }
}
```

三个要点：

1. **`Init(IPluginContext context)` 是唯一的入口**。context 上挂着全部能力域
   （`Popup` / `Widget` / `Pages` / `PageRegister` / `Wallpaper` / `Style` / `Game` / `Downloads` / `Config`），
   想用什么顺着属性摸下去就行，完整清单见第三章。
2. **返回 `false` 表示拒绝加载**，抛异常则会在插件页显示"异常"状态和原因——两种都行，但别静默吞错。
3. 每个能力调用都可能要求**权限**（见第 4 节清单里的 `permissions`），没声明会抛 `PluginPermissionException`。

## 3. 画时钟控件

插件界面就是普通 Avalonia 控件，自定义绘制覆写 `Render` 即可（摘自示例，可整段抄）：

```csharp
using Avalonia;
using Avalonia.Controls;
using Avalonia.Media;
using Avalonia.Threading;

public sealed class ClockWidget : Control
{
    private readonly DispatcherTimer _timer;

    public ClockWidget()
    {
        _timer = new DispatcherTimer { Interval = TimeSpan.FromSeconds(1) };
        _timer.Tick += (_, _) => InvalidateVisual();
        // 纪律：挂上界面才走表，摘下来就停（配合热卸载不留后台引用）
        AttachedToVisualTree += (_, _) => _timer.Start();
        DetachedFromVisualTree += (_, _) => _timer.Stop();
    }

    protected override Size MeasureOverride(Size availableSize) =>
        new(Math.Clamp(availableSize.Width, 120, 260),
            Math.Clamp(availableSize.Height, 120, 260));

    public override void Render(DrawingContext context)
    {
        double size = Math.Min(Bounds.Width, Bounds.Height);
        if (size <= 4) return;
        var center = new Point(Bounds.Width / 2, Bounds.Height / 2);
        double radius = size / 2 - 3;

        context.DrawEllipse(
            new SolidColorBrush(Color.Parse("#141822")),
            new Pen(new SolidColorBrush(Color.Parse("#2F88FF")), 2),
            center, radius, radius);

        DateTime now = DateTime.Now;
        double hourAngle = (now.Hour % 12 + now.Minute / 60.0) * (Math.PI / 6);
        double minuteAngle = (now.Minute + now.Second / 60.0) * (Math.PI / 30);
        double secondAngle = now.Second * (Math.PI / 30);

        DrawHand(context, center, hourAngle, radius * 0.5,
            new SolidColorBrush(Color.Parse("#2F88FF")), 4);
        DrawHand(context, center, minuteAngle, radius * 0.72,
            new SolidColorBrush(Color.Parse("#39C5BB")), 3);
        DrawHand(context, center, secondAngle, radius * 0.82,
            new SolidColorBrush(Color.Parse("#F26D8C")), 1.5);
    }

    private static void DrawHand(DrawingContext context, Point center, double angle,
        double length, IBrush brush, double thickness) =>
        context.DrawLine(new Pen(brush, thickness, lineCap: PenLineCap.Round),
            center,
            new Point(center.X + length * Math.Sin(angle),
                      center.Y - length * Math.Cos(angle)));
}
```

## 4. 写清单（plugin.yaml）

在项目里新建 `plugin.yaml`，开发时和 DLL 放同一个目录：

```yaml
id: MyClock            # 插件唯一 id（发布到商店时约定 = 仓库名）
name: 圆形时钟
version: 1.0.0
author: 你的名字
description: 往组件盒里加一个圆形时钟
apiVersion: 1.0.0      # 高于宿主支持的版本会被判"不兼容"
permissions: notify, widget   # 用到的权限区，逗号分隔
```

## 5. 跑起来

```bash
dotnet build -c Debug
# 把 bin/Debug/net10.0/MyClock.dll + plugin.yaml 一起复制到
# （启动器目录）/Mofumofu/plugins/myclock/
```

启动器 → 插件页 → 右上角重载按钮。你应该看到：

1. 左下角弹出 Toast"圆形时钟插件已加载喵！"（`notify` 权限）
2. 插件列表出现"圆形时钟"，状态徽章"已启用"
3. 桌面右上角"+"打开组件盒，多了一个"圆形时钟"组件，拖到桌面上开始走针

## 6. 试试权限和热装卸

- 插件页 → 选中插件 → **权限**标签 → 把"通知"关掉 → 重载插件：Toast 不再出现，
  代码里的 `context.Popup.Toast` 会抛 `PluginPermissionException`
- 概览页**停用插件**：组件从组件盒消失（宿主自动撤销了它的注册）；再**启用**又回来——这就是热装卸
- **卸载**会连 `plugins/myclock/` 目录一起删掉，测试前注意备份

## 7. 打包发布

发布 = 把四件套压成 `.nekoex`（本质是 zip，详见第四章）：

```
Example.nekoex
├── info.yaml          ← 内容和 plugin.yaml 一样（清单）
├── description.md     ← 插件详情页展示的 Markdown 简介
├── extension.dll      ← 编译产物（记得改名）
└── icon.png           ← 插件图标
```

示例项目里附了 `pack.ps1` 一键打包。发布到商店的话：建一个 GitHub 仓库（**仓库名 = 清单 id**），
Release 传 `xxx.nekoex` 资产、tag 写版本号，玩家在 下载 → 插件 添加你的仓库地址即可在线安装/更新（见第五章）。
