# 第六章：UI 扩展

启动器界面的五个扩展点：任务栏托盘、桌面小组件、页面内容注入、导航页面、主题与样式。全部走 `IPluginContext` 的对应属性，UI 线程调度宿主已代劳。

## 1. 任务栏托盘：常驻小图标

`context.Taskbar`（需要 `widget` 权限）往启动器任务栏右侧（版本选择框左边）加图标，点击行为完全由插件决定：

```csharp
ctx.Taskbar.AddWidget("clock", ctx.CreateIcon("IconClock", 18), () =>
    ctx.Popup.Dialog(new ClockWidget(), "圆形时钟"));
```

点击回调里**弹窗和跳页面二选一或组合**：

```csharp
ctx.Taskbar.AddWidget("download", ctx.CreateIcon("IconDownload", 18), () =>
{
    var task = ctx.DownloadAction.GetTaskAsync(42).Result;
    if (task is { State: Data.DownloadTaskState.Downloading })
        ctx.Popup.Dialog(BuildProgressView(task), $"任务 #{42}");
    else
        ctx.Taskbar.NavigateTo("download");   // 跳宿主下载页
});
```

> 返回的 `IDisposable` 撤销句柄在插件停用/卸载时宿主会代为调用（图标自动消失），一般不用自己管。

## 2. 桌面小组件：进组件盒

`context.Widget`（需要 `widget` 权限）把控件注册进桌面组件盒（主页右上角"+"打开），玩家拖出来摆：

```csharp
ctx.Widget.WidgetAdd("clock", new ClockWidget());
// 改标题 / 换内容：
ctx.Widget.WidgetTitleEdit("clock", "桌面时钟");
ctx.Widget.WidgetEdit("clock", new ClockWidgetV2());
```

组件 id 会自动加插件前缀（`MyPlugin.clock`），无需担心撞名。
把控件做"可卸载友好"的关键一条：**定时器在 `DetachedFromVisualTree` 里停**（见第二章 ClockWidget）。

## 3. 页面内容注入：三槽位

`context.Pages` 往**宿主已有页面**的边缘插内容，不用注册新页面：

```csharp
// 顶部横幅：只在下载页显示
ctx.Pages.Add("download", PageSlot.Banner, () => new Banner(), order: 0);

// 所有页面右下角悬浮球（Overlay 不占布局高度）
ctx.Pages.Add("*", PageSlot.Overlay, () => new FloatingBall());
```

三个槽位：`Banner`（顶部，占高度）/ `Footer`（底部，占高度）/ `Overlay`（悬浮层，不占位）。
`order` 决定同槽位的先后；工厂**每次进页面都会被调用，必须返回新控件**（同一个控件实例不能挂两处）。
`pageId` 传 `"*"` 表示所有页面。

## 4. 注册新页面

`context.PageRegister` 在左下角开始菜单里加一项自己的页面：

```csharp
ctx.PageRegister.RegisterPage("服务器监控",
    () => new ServerMonitorView(),      // 每次进入页面都会调用，必须返回新控件
    ctx.CreateIcon("IconServer", 16));
```

## 5. 主题跟随：别硬编码颜色

`context.Theme` 读宿主当前主题色，出 UI 的插件用它配色，玩家换主题自动跟手：

```csharp
IBrush AccentBrush() => new SolidColorBrush(Color.Parse(ctx.Theme.AccentColorHex));
ctx.Theme.ThemeChanged += () => InvalidateVisual();   // 自绘控件换主题时重画
ctx.Theme.IsLight;   // "dark" / "light"
```

## 6. 样式与主题库

`context.Style` 三种加载方式（都返回撤销句柄）：

```csharp
// ① 散装 axaml（开发期随改随看，相对插件目录）
ctx.Style.StyleEdit("theme.axaml");

// ② 打进 DLL 的 axaml（csproj 里 <AvaloniaResource Include="theme.axaml" />）
var stream = AssetLoader.Open(new Uri("avares://MyPlugin/theme.axaml"));
ctx.Style.StyleEdit(stream);

// ③ 主题库标准入口：插件自带 Material.Avalonia 等库，实例化其主题类直接合入全局
ctx.Style.StyleEdit(new MaterialTheme());
```

axaml 根节点必须是 `<Styles>`。资源键请加插件 Id 前缀（如 `MyClock.BackgroundBrush`）避免多插件互抢。

> 主题库注意：随包依赖会被宿主装入默认 ALC 让 `avares://` 可解析，代价是这些 DLL 被钉住——
> **用主题库的插件可能要重启启动器才能完全卸载**；主题库的 Avalonia 版本必须与宿主一致（当前 12.1.4）。
