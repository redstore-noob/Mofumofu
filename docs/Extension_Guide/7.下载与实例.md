# 第七章：下载与实例

四个接口覆盖"查版本 → 装实例 → 下资源 → 管模组 → 下 Java"的完整链路。
网络类失败全部直接抛异常（消息可直接展示给玩家），进度走 `IProgress<T>`，取消走 `CancellationToken`。

## 1. 资源搜索与安装（Modrinth）

`context.ResourceDownload`——搜模组/光影/资源包并装进实例（走宿主镜像体系，境内可用）：

```csharp
// 搜索：按关键词 + 游戏版本 + 加载器过滤
var hits = await ctx.ResourceDownload.SearchAsync(
    "sodium", ResourceKind.Mod, gameVersion: "1.21.4", loader: "fabric");

// 查某项目的可下载版本
var files = await ctx.ResourceDownload.GetFilesAsync(hits[0].ProjectId, "1.21.4", "fabric");

// 下载并装进实例（mod 会自动补依赖，目标目录按种类自动选：mods / shaderpacks / resourcepacks）
var result = await ctx.ResourceDownload.DownloadAsync(
    files[0].VersionId, ResourceKind.Mod, instanceId: "survival",
    gameVersion: "1.21.4", loader: "fabric",
    progress: new Progress<(int Completed, int Total, string Detail)>(p =>
        ctx.Popup.Toast($"下载中 {p.Completed}/{p.Total}")));
```

`ResourceKind` 三选一：`Mod` / `Shader` / `ResourcePack`。CurseForge 源暂未开放，当前全部走 Modrinth。

## 2. 安装游戏实例（原版或带加载器）

`context.Downloads`：

```csharp
// ① 查官方版本清单
var versions = await ctx.Downloads.GetVersionsAsync();

// ② 带加载器安装：先查该游戏版本的加载器版本列表
var loaderVersions = await ctx.Downloads.GetLoaderVersionsAsync(
    ModLoaderType.Fabric, "1.21.4");

// ③ 安装（LoaderVersion 传 null = 自动选最新稳定版；原版依赖自动补装）
var installed = await ctx.Downloads.DownloadAsync(
    new InstanceDownloadRequest(
        VersionId: "1.21.4",
        Loader: ModLoaderType.Fabric,
        LoaderVersion: null,
        DisplayName: "生存养老服"),
    progress: new Progress<InstanceDownloadProgress>(p =>
        ctx.Popup.Toast($"{p.Phase} {p.Percent:0}%")));

ctx.Popup.Toast($"已装到实例 {installed.Id}");   // Id = versions/ 下实际目录名
```

> 返回的 `InstanceInfo.Id` 可能和版本号不同（如 `1.21.4-fabric`），后续操作一律用这个 Id。
> 插件只能**安装**实例，不能启动任意实例——启动走 `context.Game.LaunchSelectedAsync()`（只能启玩家选中的那个）。

## 3. 实例模组管理

`context.InstanceAction`——列 / 启停 / 删实例 mods 目录里的模组：

```csharp
// 列出（含停用态；文件名一律是"启用态"名字）
var mods = await ctx.InstanceAction.GetModsAsync("survival");
foreach (var mod in mods.Where(m => !m.Enabled))
    ctx.Popup.Toast($"发现停用模组：{mod.FileName}");

// 停用 / 启用（.jar ↔ .jar.disabled 改名）
ctx.InstanceAction.SetModEnabled("survival", "sodium.jar", enabled: false);

// 删除（不可恢复）
ctx.InstanceAction.DeleteMod("survival", "sodium.jar");
```

**权限提醒**：列表要 `readonly`，启停和删除要 **`instanceWrite`**（删除不可恢复，玩家会盯着这个开关）。

## 4. Java 运行时

`context.Java`——清单 / 安装 / 本机检测：

```csharp
// 宿主支持的主版本（当前 8 / 11 / 17 / 21 / 25）
foreach (var major in ctx.Java.SupportedMajorVersions) { }

// 装 Java 21 到游戏目录 runtime/（已存在自动跳过；字节级进度）
var installed = await ctx.Java.InstallAsync(21,
    new Progress<(string Phase, long CompletedBytes, long TotalBytes)>(p =>
        ctx.Popup.Toast($"{p.Phase}")));
ctx.Log("装好了：" + installed.JavaPath);

// 本机检测到的全部 Java（环境变量 / 注册表 / 常见目录 / runtime/）
var found = await ctx.Java.GetInstalledAsync();
```

## 权限速查

| 本页用到的 | 权限区 |
|---|---|
| 查询类（版本清单 / 搜索 / 文件列表 / Java 清单 / 本机检测） | `networkReadonly` / `readonly` |
| 安装类（实例 / 资源 / Java） | `network` |
| mods 启停 / 删除 | `instanceWrite` |
