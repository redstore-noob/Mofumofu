# 第三章：API 对照表

契约库命名空间：`Mofumofu.ExtensionAPI`。子域：`UI`（界面能力）、`Game`（游戏/实例）、`Downloads`（实例与资源下载）、`Java`（运行时）、`Actions`（钩子）、`Data`（全部枚举与数据 record）、`Tools`（杂项）。

**通用约定**

- 网络与磁盘操作一律 `Task`/`Task<T>`；失败**直接抛异常**（消息面向玩家可读），列表查询不返回 null
- 会撤销的注册一律返回 `IDisposable`：插件停用/卸载时宿主代为 Dispose，插件通常不用自己管
- 权限不足抛 `PluginPermissionException`（`Permission` 属性 = 所需权限区名）
- UI 相关调用宿主已做线程调度，插件在任意线程调都可以；事件/钩子回调统一在 UI 线程
- 数据 record 全部在 `Mofumofu.ExtensionAPI.Data`，按"数据进 Data/、接口留在域目录"的规矩摆放

## 0. 插件入口 `IMofuPlugin`

| 成员 | 说明 |
|---|---|
| `string Name` | 显示名，玩家可见 |
| `Version Version` | 插件版本 |
| `PluginTypeEnum ExtensionType` | 分类：Tool / Theme / General / Optimize / Patch / Function |
| `string Description` | 一句话简介 |
| `Boolean Init(IPluginContext context)` | 加载时调用一次；返回 false = 拒绝加载；抛异常 = 插件页显示"异常"和原因 |

## 1. 权限区总表

清单 `permissions:` 里声明（逗号分隔），玩家在 插件页 → 权限 标签逐项开关（即时生效、持久化）。未声明而调用 → 抛 `PluginPermissionException`。

| 权限区 | 管辖的能力 |
|---|---|
| `notify` | `Popup.Toast` / `Popup.Dialog`、`SystemTray.ShowNotification` |
| `widget` | `IWidgetAdd` 全部方法、`Taskbar.AddWidget`、`SystemTray.AddMenuItem` |
| `network` | `Downloads.DownloadAsync`、`ResourceDownload.DownloadAsync`、`Java.InstallAsync`、`DownloadAction.Cancel` / `SetPaused`、商店安装 |
| `networkReadonly` | `Downloads.GetVersionsAsync` / `GetLoaderVersionsAsync`、`ResourceDownload.SearchAsync` / `GetFilesAsync`、`Java.GetAvailableAsync`、`DownloadAction.GetTaskAsync` 与完成/失败通知 |
| `storage` | `IConfig.ConfigAdd` / `ConfigRemove` |
| `readonly` | `IGameLaunch` 查询与事件订阅、`Java.GetInstalledAsync`、`InstanceAction.GetModsAsync` |
| `instanceWrite` | `InstanceAction.SetModEnabled` / `DeleteMod`（删除不可恢复） |
| `serverStatus` | 预留（`IServerStatus` 未开放） |

## 3. UI 域（`...UI`）

### `IPopup`
| 成员 | 权限 | 行为 |
|---|---|---|
| `Toast(string message)` | notify | 左下角轻提示（自动带插件名前缀） |
| `Dialog(Control content, string title)` | notify | 居中弹窗，内容自建 |

### `IPageContentHost`
| 成员 | 行为 |
|---|---|
| `IDisposable Add(string pageId, PageSlot slot, Func<Control> factory, int order = 0)` | `pageId` 如 `"home"`/`"download"`，`"*"` = 所有页面；`PageSlot` = Banner / Footer / Overlay（悬浮不占位）；每次进页面重建，工厂必须返回新控件 |

### `IPageRegister`
| 成员 | 行为 |
|---|---|
| `IDisposable RegisterPage(string pageName, Func<Control> createPage, Control icon)` | 出现在左下角开始菜单；icon 为任意控件 |

### `IWidgetAdd`
| 成员 | 权限 | 行为 |
|---|---|---|
| `IDisposable WidgetAdd(string id, Control widget)` | widget | 注册进桌面组件盒（id 自动加插件前缀） |
| `WidgetTitleEdit(id, newTitle)` | widget | 改标题 |
| `WidgetEdit(id, newWidget)` | widget | 换内容 |

### `ITaskbarTray`（任务栏右侧）
| 成员 | 权限 | 行为 |
|---|---|---|
| `IDisposable AddWidget(string id, Control icon, Action click)` | widget | 图标出现在版本选择框左侧，样式与任务栏一致；点击回调里自己决定弹 `Popup.Dialog` 还是 `NavigateTo`（二选一或组合） |
| `void NavigateTo(string pageId)` | 无 | 跳内置页或插件注册页 |

### `ISystemTray`（系统托盘常驻）
| 成员 | 权限 | 行为 |
|---|---|---|
| `IDisposable AddMenuItem(string label, Action click)` | widget | 托盘菜单「退出」之前插入；启动器缩到托盘时依然可达 |
| `void ShowNotification(string title, string message)` | notify | 托盘气泡（平台不支持时回退启动器 Toast） |

### `IWallpaperEdit`
| 成员 | 行为 |
|---|---|
| `IDisposable WallpaperTakeOver(Control wallpaperContent)` | 接管背景层，内置壁纸停用；同时只有一个插件生效，后到者顶掉先到者；Dispose 恢复 |

### `IStyleLoad`
| 成员 | 行为 |
|---|---|
| `StyleEdit(Stream xamlStream)` | DLL 内嵌 axaml 资源流（根节点须为 `<Styles>`） |
| `StyleEdit(string xamlPath)` | 插件目录散装 axaml（相对路径），开发期随改随看 |
| `StyleEdit(IStyle styles)` | **主题库标准入口**：插件自带 Material.Avalonia 等 DLL，实例化其主题类直接合入全局 |

> 主题库注意：宿主会把插件随包的依赖 DLL 装入宿主默认 ALC 让 `avares://` 可解析——这些 DLL 会被钉住，**用主题库的插件可能要重启启动器才能完全卸载**。资源键请加插件 Id 前缀避免互相覆盖。主题库的 Avalonia 版本必须与宿主一致（当前 12.1.4）。

### `ITheme`
| 成员 | 行为 |
|---|---|
| `string AccentColorHex` | 当前主题色 `#RRGGBB`——出 UI 的插件别硬编码颜色 |
| `string ThemeMode` / `bool IsLight` | `"dark"` / `"light"` |
| `event Action ThemeChanged` | 玩家换主题/主题色时触发；停用自动退订 |

## 4. Game 域（`...Game`）

### `IGameLaunch`
| 成员 | 权限 | 行为 |
|---|---|---|
| `GetInstancesAsync(ct)` | readonly | 本地实例列表（各游戏目录 versions/ 全部） |
| `GetSelectedInstanceAsync(ct)` | readonly | 玩家当前选中实例；未选中 null |
| `LaunchSelectedAsync(ct)` | 无 | 只启动玩家选中的实例（用户意图即授权）；进程启动即返回 |
| `bool IsGameRunning` | 无 | 游戏是否运行中 |
| `event Action GameLaunched` | readonly（订阅时） | 进程启动成功，UI 线程回调 |
| `event Action<int> GameExited` | readonly（订阅时） | 游戏退出（UI 线程），退出码；手动停止 -1 |

### `IInstanceAction`
| 成员 | 权限 | 行为 |
|---|---|---|
| `GetModsAsync(instanceId)` | readonly | 列出实例 mods/（含停用态）；文件名一律用启用态名字 |
| `SetModEnabled(instanceId, fileName, enabled)` | instanceWrite | `.jar` ↔ `.jar.disabled` 改名 |
| `DeleteMod(instanceId, fileName)` | instanceWrite | 删除文件，不可恢复 |

## 5. 下载域（`...Downloads`）

### `IInstanceDownload`
| 成员 | 权限 | 行为 |
|---|---|---|
| `GetVersionsAsync(ct)` | networkReadonly | 官方版本清单（原版） |
| `GetLoaderVersionsAsync(loader, gameVersion, ct)` | networkReadonly | 某游戏版本可用的加载器版本（Fabric / Forge / NeoForge / Quilt） |
| `DownloadAsync(request, progress, ct)` | network | 安装实例（原版或带加载器，加载器自动补装原版依赖）；`LoaderVersion` 传 null = 最新稳定版；返回的 `InstanceInfo.Id` 是 versions/ 实际目录名 |

### `IResourceDownload`（Modrinth；走宿主镜像体系）
| 成员 | 权限 | 行为 |
|---|---|---|
| `SearchAsync(query, kind, gameVersion, loader, limit, offset, ct)` | networkReadonly | 搜索/浏览；query 空 = 热门浏览 |
| `GetFilesAsync(projectId, gameVersion, loader, ct)` | networkReadonly | 项目可下载版本列表 |
| `DownloadAsync(versionId, kind, instanceId, ..., includeDependencies, progress, ct)` | network | 装进实例（mods / shaderpacks / resourcepacks 按种类自动选目录；mod 自动补依赖） |

### `IJavaDownload`
| 成员 | 权限 | 行为 |
|---|---|---|
| `SupportedMajorVersions` | 无 | 当前 8 / 11 / 17 / 21 / 25 |
| `GetAvailableAsync(ct)` | networkReadonly | Mojang 官方运行时清单 |
| `InstallAsync(majorVersion, progress, ct)` | network | 装到游戏目录 runtime/，已存在自动跳过；清单没有该主版本返回 null |
| `GetInstalledAsync(ct)` | readonly | 本机检测到的全部 Java |

## 6. 钩子（`...Actions`，插件实现的接口）

钩子与事件的区别：**事件是事后通知，钩子能参与决策**。钩子全部在 UI 线程调用、单个 5 秒超时、抛异常按"不作为"处理并记日志。

### `ILaunchAction`（启动过程钩子）
| 成员 | 行为 |
|---|---|
| `Task<Boolean> LaunchingAsync(ILaunchContext launch)` | 启动前调用；true = 放行，false / `launch.Cancel(reason)` = 拦截（原因展示给玩家）；`launch.JvmArguments.Add(...)` 注入的参数会被采用 |
| `GameCrashedHook(string crashedLog)` | 游戏崩溃退出时调用（带诊断摘要） |
| `GameStoppedHook(GameSessionData session)` | 正常退出 / 手动停止时调用；`session` 含 `PlayDuration`（本次时长）、`StartedAt`、`ExitCode` 等；累计时长用 `context.Game.GetInstancesAsync` 查 |

`ILaunchContext`：`InstanceId` / `VersionId` / `GameDirectory`（只读事实）+ `IList<string> JvmArguments`（唯一可写面）+ `Cancel(reason)`。

### `IDownloadAction`（下载任务动作）
| 成员 | 权限 | 行为 |
|---|---|---|
| `GetTaskAsync(taskNumber)` | networkReadonly | 按 4 位编号查快照；不存在返回 null |
| `Cancel(taskNumber)` / `SetPaused(taskNumber, paused)` | network | 按编号取消（含清理）/ 暂停恢复 |
| `DownloadCompletedHook(taskNumber, title)` | networkReadonly | 任务完成通知 |
| `DownloadFailedHook(taskNumber, title, reason)` | networkReadonly | 任务失败通知 |

> 任务编号（0001~9999）会话内唯一，**任务结束后回收复用**——不要长期缓存编号。下载页任务卡标题前的 `#0007` 就是它。

## 9. 清单（info.yaml / plugin.yaml）字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 唯一 id；**发布商店时约定 = GitHub 仓库名** |
| `name` | ✅ | 显示名 |
| `version` | ✅ | 版本号 |
| `author` |  | 作者 |
| `description` |  | 一句话简介（详情页优先展示 description.md） |
| `apiVersion` |  | 所需宿主 API 版本，高于宿主 → "不兼容"（当前 1.0.0） |
| `permissions` |  | 权限区，逗号分隔（如 `notify, widget`） |

## 10. 版本与兼容约定

- 宿主当前实现 **API 1.0.0**；清单 `apiVersion` 高于它 → 拒绝加载并显示"不兼容"
- 契约只加不改：新版本宿主对旧插件向后兼容；删除/改名成员会升主版本号
