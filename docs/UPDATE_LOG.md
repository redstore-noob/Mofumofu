# Mofumofu 更新日志（简体中文）

> 因为我比较懒，所以这个更新日志实际上是0.3.0开始写的🥺

## 0.3.1

- 前端界面

  - 修复了部分界面由于控件导致高亮色块只显示在文字内一小部分的问题

  - 移除了当窗口失焦之后毛玻璃关闭的功能（useless）

  - 开始菜单的文字不再可选中

  - 设置页大改：内存分配、默认 Java、已安装 Java 管理归到游戏设置，语言切换改为轨道地球动画

  - 服务器页改版，新增开服向导（版本/核心选择、配置、安装进度一站式完成）

  - 底栏新增实例选择器：搜索、最近使用、全部实例三分组，随手切换

  - 登录改为内嵌浏览窗口（WebView2），风格与主窗口统一；其他平台回退系统浏览器

  - 音乐页、下载页样式翻新，磁贴淡入过渡

- 体验优化

  - 修复了之前的版本中进入下载页由于列表直接加载结束才进入导致的卡顿问题

  - 修复了以管理员身份运行时，启动器拉起的浏览器因继承提权令牌与桌面现有实例冲突的问题

  - 全语言文案与旗帜图标更新，语言包覆盖简中/繁中/英/日/俄/德/世界语

- 后端与重构

  - Mofu Agent 会话运行时重构，支持注入任务上下文，补充回归用例

  - 扩展 API 与日志分享插件小幅精简

  - 全项目移除 XML 文档注释，精简下载、启动、日志等实现

- 其他

  - 移除了“截图画廊”（在已经有了截图小组件的情况下，这个页面相对冗余）

  - 补充了主界面、下载页、关于页的项目展示截图
