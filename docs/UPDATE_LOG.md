# 更新日志

> 记录玩家可见的功能变化。技术细节与踩坑记录见 `.workbuddy/memory/`。

## 2026-11-13

### 新增：截图画廊

- 主页「截图墙」组件从空壳改为真实数据：扫描共享目录 `<游戏目录>/screenshots` 与各实例隔离目录下的 `screenshots`，按拍摄时间倒序展示最近 6 张。
- 新增独立页面「截图画廊」：左栏按来源筛选（全部 / 共享目录 / 各实例），右栏缩略图网格，点开进入大图预览。
- 大图预览支持上一张 / 下一张、打开所在文件夹、复制路径，分辨率与文件大小一并显示。
- 缩略图走独立的降采样缓存（内存 LRU + 磁盘 PNG），4K 原图不会整张塞进内存；原图被替换或重新截图后缓存自动失效。
- 读取图片宽高只解析 PNG / JPEG 文件头，不做整图解码。

### 新增：模组批量更新检查

- 实例页「内容 → 模组」新增「检查更新」：读取 `mods/*.jar` 的 SHA-1，向 Modrinth 批量反查文件归属，再按当前实例的 MC 版本与加载器查询可用新版本。
- 检查结果列在模组列表上方：项目名、版本变化（如 `1.2.3 → 1.3.0`）、单独「更新」与「全部更新」。
- 更新时旧文件先移进 `mods/.mofu-backup/<时间戳>/`，下载失败会把旧文件放回原位；新文件名变化时自动刷新列表。
- Modrinth 不认识的哈希（手动放入或来自其他站点）会被跳过，不凭文件名猜测项目。

### 新增：CurseForge 整合包导入

- 拖入 CurseForge 格式的 `.zip` 整合包不再提示「暂不支持」，改为真实安装：解析 `manifest.json`、解压 `overrides/`、按 `projectID` / `fileID` 换取下载地址并下载到 `mods/`。
- 使用设置页已有的 CurseForge API Key；未填写时直接提示去「设置 → 下载」补上，不会装到一半。
- 作者关闭第三方分发的文件会被跳过，安装结束后提示有多少个文件未装上，而不是整包失败。
- 加载器安装复用 .mrpack 的同一条管线（Fabric / Quilt / Forge / NeoForge）。

### 改进：插件注册的工具页

- `IPageRegister.RegisterPage(..., isTool: true)` 注册的页面现在真的会出现在开始菜单的「工具」下拉栏里，点击直达该页面（此前行为与普通页面一致）。

### 修复：语言包缺口

- 补齐 `de-DE` / `eo` / `ja-JP` / `ru-RU` 缺失的整份 `Memory.json`（11 个键）与存档备份/导出、主页服务器配置相关文案，各 30 个键。
- 补齐 `zh-TW` 缺失的 19 个键。
- 七个语种现均为 2238 个键，键集合完全一致。
